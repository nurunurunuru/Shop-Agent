# Shop Agent v2 — AI সেলস এজেন্ট + ইনবক্স + অর্ডার সিস্টেম

Messenger, Instagram, WhatsApp আর পোস্টের কমেন্ট: সব এক ড্যাশবোর্ডে। AI নিজে কথা বলে, ছবি/ভয়েস বোঝে, প্রোডাক্ট কার্ড পাঠায়, অর্ডার নেয়, কুরিয়ার বুক করে, ট্র্যাকিং জানায়।

## চালানো (৩ মিনিট)

```
npm install
copy .env.example .env      (Mac/Linux: cp .env.example .env)
npm start
```
ব্রাউজারে `http://localhost:3000` খুলুন → প্রথমবার **মালিকের অ্যাকাউন্ট** বানাতে বলবে।

`.env` এ আগের কীগুলো (VERIFY_TOKEN, PAGE_ACCESS_TOKEN, WHATSAPP_*, GEMINI_API_KEY) বসান। **Webhook URL একই (`/webhook`)**, তাই Meta-র সেটিং বদলাতে হবে না। নতুন যা লাগবে: `PUBLIC_URL` (আপনার ngrok/Render লিংক, প্রোডাক্টের ছবি Meta-কে পাঠাতে)।
আগের `data.json` এর ক্যাটালগ আসবে না; প্রোডাক্ট নতুন করে যোগ করতে হবে।

## প্রথমে এভাবে টেস্ট করুন (Meta ছাড়াই)

1. **🛍 প্রোডাক্ট** ট্যাবে ২-৩টা প্রোডাক্ট দিন (ছবি, দাম, সাইজ ও স্টক `M:5` ফরম্যাটে)।
2. ওপরের **🧪 সিমুলেটর** খুলে কাস্টমার সেজে লিখুন: "পাঞ্জাবি আছে?" → কার্ড আসবে → "অর্ডার করুন" চাপুন → নাম/ফোন/ঠিকানা → কনফার্ম → বিল আসবে।
3. **🧾 অর্ডার** ট্যাবে অর্ডার দেখুন, "কুরিয়ারে বুক করুন" চাপুন, তারপর ডেলিভারড করুন; সিমুলেটরে আপডেটগুলো দেখবেন।
4. `.env` এ `GEMINI_API_KEY` না থাকলে সিস্টেম "ডেমো ব্রেইন" দিয়ে চলে: শুধু ফ্লো দেখার জন্য, বুদ্ধি নেই। আসল কথা বলার জন্য key দিন।

## কী কী আছে

| | |
|---|---|
| **ইনবক্স** | সব প্ল্যাটফর্ম এক জায়গায়; নাম/ফোন/অর্ডার নং/চ্যাটের কথা দিয়ে search; ফিল্টার; অপঠিত |
| **কাস্টমার প্রোফাইল** | নাম, ফোন, ঠিকানা, সম্বোধন, ট্যাগ, টিমের নোট, আগের অর্ডার/রিটার্ন/বাতিলের হিসাব, একই ফোনের অন্য চ্যাট |
| **টিম** | যত খুশি টিমমেট; চ্যাট assign করলে নোটিফিকেশন (ব্রাউজারেও); "আমি নিচ্ছি" (নির্দিষ্ট সময় পর AI-তে ফেরে); AI-কে ফেরত দেওয়া |
| **AI** | ভদ্র সেলসম্যানের সুরে, স্যার/ম্যাম ঠিক রেখে; ছবি দেখে ক্যাটালগ থেকে প্রোডাক্ট মেলায়; ভয়েস বোঝে; আগের কথা/অর্ডার মনে রাখে; জানা না থাকলে/অভিযোগে টিমকে ডাকে |
| **কার্ড ও বাটন** | প্রোডাক্ট কার্ড (ছবি, নাম, দাম) + ২ বাটন: "বিস্তারিত" ও "অর্ডার করুন" |
| **অর্ডার** | ঠিকানা/ফোন নেওয়া → সামারি → কনফার্ম → চ্যাটে বিল; স্টক কমে/বাতিলে ফেরে; স্টক না থাকলে সুন্দর উত্তর ও বিকল্প |
| **অর্ডার ম্যানেজমেন্ট** | পেন্ডিং → প্রসেসিং → শিপড → ডেলিভারড; বাতিল/রিটার্ন (কারণসহ); ক্যাশ হাতে এসেছে চিহ্ন; নোট; ইতিহাস; টিম থেকেও অর্ডার নেওয়া |
| **কুরিয়ার** | ১ ক্লিকে বুক; ট্র্যাকিং কোড/লিংক চ্যাটে যায়; Steadfast স্ট্যাটাস নিজে নিজে মেলে |
| **ডেলিভারির পর** | ডেলিভারড হলে ধন্যবাদ + রেটিং বাটন; খারাপ রেটিং → টিমকে ডাকে; ভালো হলে রিভিউ লিংক |
| **লিড/ফলো-আপ** | আগ্রহী কাস্টমার নিজে জমা হয়; ফলো-আপের তারিখ, কলের ফল লেখা; স্মার্ট রিমাইন্ডার (চালু করলে) |
| **কমেন্ট** | পোস্টে কমেন্টে নাম ধরে উত্তর + ইনবক্সে মেসেজ; কমেন্ট-ইনবক্সের কথা এক চ্যাটে |
| **রিপোর্ট** | আজ/গতকাল/৭ দিন: চ্যাট, AI বনাম টিমের উত্তর, অর্ডার, বিক্রি, কেন অর্ডার হারাচ্ছি, স্টক কম |
| **AI সহকারী** | চ্যাটের সারাংশ, রিপ্লাই ড্রাফট, প্রশ্ন করলে উত্তর |
| **এজেন্ট ডেস্ক** | নিজের ভাষায় নিয়ম লিখুন → ড্রাফট টেস্ট → এক ক্লিকে লাইভ → দরকারে আগের ভার্সনে ফেরা |
| **প্র্যাক্টিস মোড** | শুরুতে AI শুধু ড্রাফট বানায় (কাস্টমারকে যায় না), আপনি দেখে পাঠান। ⚙ সেটিংসে "AI লাইভ" চালু করলে সবাইকে সরাসরি উত্তর দেয় |

## Meta-তে যা চালু করতে হবে

- **Messenger**: Webhook fields: `messages`, `messaging_postbacks`, আর কমেন্টের জন্য `feed`
- **Instagram**: `messages`, `messaging_postbacks`, কমেন্টের জন্য `comments`
- **WhatsApp**: `messages`
- সবার জন্য লাইভ করতে Meta App Review লাগবেই (আগের মতোই)।

## সৎ সীমাবদ্ধতা (এগুলো জানা থাকলে ধাক্কা খাবেন না)

**যা আমি টেস্ট করেছি** (স্বয়ংক্রিয় টেস্টে, ৬৯ + ১৬ + ২৩টা পাস): লগইন/টিম, ইনবক্স, search, অর্ডার ফ্লো, স্টক, কুরিয়ার (mock), assign/নোটিফিকেশন, ড্রাফট, ড্যাশবোর্ডের প্রতিটা ট্যাব, এবং নকল Gemini দিয়ে AI-র পথ (JSON, ছবি মেলানো, এরর)।

**যা আমি টেস্ট করতে পারিনি** (আমার পরিবেশ থেকে Meta/Google/Steadfast-এ যাওয়া যায় না): আসল Meta-য় পাঠানো ও কার্ড/বাটনের চেহারা, আসল Gemini-র উত্তরের মান, আসল Steadfast API, কমেন্ট থেকে প্রাইভেট রিপ্লাই। এগুলোতে প্রথমবার ছোটখাটো সমস্যা হতে পারে। হলে সার্ভারের টার্মিনালের লাল লেখা আর ড্যাশবোর্ডে মেসেজের নিচের "⚠ পাঠানো যায়নি" লেখাটা আমাকে দেখান।

- **২৪ ঘণ্টার নিয়ম**: কাস্টমারের শেষ মেসেজের ২৪ ঘণ্টা পরে Meta সাধারণ মেসেজ পাঠাতে দেয় না (WhatsApp-এ টেমপ্লেট লাগে)। তাই দেরিতে ডেলিভারি/ট্র্যাকিং আপডেট পাঠানো ব্যর্থ হতে পারে; ড্যাশবোর্ডে লাল ⚠ দেখাবে। ফলো-আপ রিমাইন্ডার তাই ২৩ ঘণ্টার ভেতরে সীমাবদ্ধ।
- **ছবি মেলানো**: শুধু আপনার আপলোড করা প্রোডাক্ট ছবির সাথে (সর্বোচ্চ ১২টা প্রোডাক্ট, ছবি ≤৬০০KB)। ক্যাটালগ বড় হলে আরও ভালো কৌশল লাগবে।
- **ডেলিভারি চার্জ**: ঠিকানায় "ঢাকা"/পরিচিত এলাকার নাম থাকলে ঢাকার ভেতরের চার্জ ধরে। ভুল হলে অর্ডার দেখে সংশোধন করুন।
- **ডেটাবেস**: JSON ফাইল (`data/store.json`)। শত শত অর্ডার/দিনে ঠিক আছে; বড় হলে Postgres-এ সরাতে হবে। `data/` ফোল্ডার নিয়মিত ব্যাকআপ রাখুন।
- **Steadfast**: `COURIER_MODE=steadfast` + API key দিলে চলবে। Pathao এখনো নেই। Steadfast-এর "cancelled" স্ট্যাটাসকে আমি "রিটার্ন" ধরেছি, আপনার অভিজ্ঞতায় মিললে ঠিক, না মিললে বলুন।
- **এখনো বানানো হয়নি**: অন্য ব্যবসার sign up/পেজ connect/billing (multi-tenant), ডেলিভারির দিন সকালে রিমাইন্ডার, উত্তর না পাওয়া কমেন্টে দ্বিতীয়বার রিপ্লাই, কুরিয়ারের ফ্রড/ঝুঁকি চেক, ভিডিও বোঝা।
- **হোস্টিং**: Render-এর ফ্রি প্ল্যানে ফাইল সংরক্ষিত থাকে না (রিস্টার্টে `data/` মুছে যায়)। আসল ব্যবসা চালাতে ডিস্ক-সহ হোস্টিং লাগবে। এটা deploy-এর ধাপে একসাথে ঠিক করব।
