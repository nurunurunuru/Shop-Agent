# Shop Agent — AI সেলস এজেন্ট + ইনবক্স + অর্ডার ও হিসাব

Messenger, Instagram, WhatsApp ও পোস্টের কমেন্ট: সব এক ড্যাশবোর্ডে। AI কথা বলে, ছবি/ভয়েস বোঝে, প্রোডাক্ট কার্ড পাঠায়, অর্ডার নেয়, কুরিয়ার বুক করে, রিটার্ন সামলায়, টাকার হিসাব রাখে।

## চালানো

```
npm install
copy .env.example .env      (Mac/Linux: cp .env.example .env)
npm start
```
`http://localhost:3000` খুলে প্রথমবার মালিকের অ্যাকাউন্ট খুলুন। `.env.example`-এ প্রতিটা সেটিংয়ের ব্যাখ্যা আছে।

## আগের সংস্করণ থেকে আপডেট করলে

- `.env` আর `data/` ফোল্ডার ছোঁবেন না। zip-এ এ দুটো নেই।
- পুরোনো ডেটা নিজে নতুন কাঠামোতে বদলে যায় (সাইজ "M, L, XL" এক লাইনে ছিলে আলাদা সাইজ হয়, টিমমেটরা "আংশিক" অ্যাক্সেস পায়)।
- **`ai.js` আপনি নিজে বদলে থাকলে** (যেমন Gemini retry): নতুন `ai.js`-এ retry + ব্যাকআপ মডেল (`GEMINI_FALLBACK_MODELS`) আগে থেকেই আছে।
- **Render-এ ডিপ্লয়ের আগে ⚙ সেটিংস → 💾 ব্যাকআপ ডাউনলোড করুন** (নতুন সংস্করণ চালু থাকলে)। Render-এর ফ্রি প্ল্যানে ডিপ্লয়/রিস্টার্টে `data/` (অর্ডার, চ্যাট, প্রোডাক্ট, ছবি) মুছে যায়। স্থায়ী সমাধান: Render-এ Disk লাগিয়ে `.env`/Environment-এ `DATA_DIR=/var/data` (ডিস্কের পথ) দিন।

## Meta-তে যা চালু থাকতে হবে

| কাজ | কী লাগে |
|---|---|
| মেসেজ | Webhook ফিল্ড `messages` |
| **কার্ডের বাটন** (বিস্তারিত / অর্ডার করুন / সাইজ / কনফার্ম) | Webhook ফিল্ড **`messaging_postbacks`** (না থাকলে বাটন চাপলে কিছুই হয় না) |
| পোস্টের কমেন্ট | ফিল্ড **`feed`** (Instagram: `comments`) + অনুমতি `pages_read_engagement`, `pages_manage_engagement` |
| আসল Facebook নাম ও ছবি | App-এ **"Business Asset User Profile Access"** ফিচার (App Review) |
| ২৪ ঘণ্টা পরে টিমের নিজের লেখা মেসেজ | **"Human Agent"** ফিচার (App Review) |

⚙ সেটিংস → 🩺 **Meta সংযোগ পরীক্ষা** চাপলে দেখায় কোন ফিল্ড সাবস্ক্রাইব করা নেই; "ঠিক করুন" চাপলে নিজে সাবস্ক্রাইব করার চেষ্টা করে। Instagram-এর ফিল্ড Meta Developer-এ হাতে টিক দিতে হয়।

## কী কী আছে

- **ইনবক্স:** আসল নাম ও প্রোফাইল ছবি, চ্যানেলের আইকন, প্রায়োরিটি ট্যাগ (🔥হাই / নরমাল / ⬇লো, অটো, চাইলে হাতে বদলান), 🆕নতুন / 🔁পুরোনো / ⭐রেগুলার, ✅ কিনেছেন চিহ্ন। ফিল্টার: প্রায়োরিটি, ধরন, কে অ্যাসাইন, ট্যাগ, "শুধু যারা কিনেছেন", প্ল্যাটফর্ম। search: নাম, ফোন, অর্ডার নং, চ্যাটের কথা।
- **প্রায়োরিটির নিয়ম:** ২+ ডেলিভারড = রেগুলার = হাই; অর্ডার চলছে/চলমান = হাই; টিম দরকার = হাই; আগ্রহী লিড (৩ দিন) = হাই; বারবার বাতিল/রিটার্ন বা ১৪ দিন নিষ্ক্রিয় = লো।
- **টিম চ্যাটে ফাইল:** 📎 দিয়ে ছবি/MP4 ভিডিও/PDF/Word/Excel (পিসি বা মোবাইল থেকে, ছবি অটো ছোট হয়), 🛍 দিয়ে প্রোডাক্ট কার্ড।
- **পারমিশন:** মালিক, আর টিমমেটকে প্রিসেট (ফুল / আংশিক / বেসিক) বা কাস্টম ৮টা পারমিশন; "শুধু অ্যাসাইন করা চ্যাট দেখবে" অপশন।
- **টিমের কাজ:** 👥 টিমে নামে ক্লিক করলে কার সাথে কথা বলছে, কত মেসেজ, কী অর্ডার; ইনবক্সে "কার চ্যাট" ফিল্টার।
- **সাইজ:** একবার বললে (এমনকি অর্ডারের কথার সাথে) আর জিজ্ঞেস করে না; আগের অর্ডারের সাইজ মনে রাখে।
- **রিটার্ন:** ফেরত এলে কাস্টমারকে কারণ জিজ্ঞেস (বাটন বা নিজের কথায়), কারণ সংরক্ষণ, আবার কেনার কার্ড, রিপোর্টে "কেন হারাচ্ছি"।
- **হিসাব:** আয় ধরা হয় **শুধু ডেলিভারড হলে**। না নিয়ে ফেরত = আয় নেই, রিটার্ন খরচ ক্ষতি। ডেলিভারির পর ফেরত = আয় বাতিল + কুরিয়ার ও রিটার্ন খরচ ক্ষতি। বাতিল = হিসাবে নেই। প্রোডাক্টে ক্রয়মূল্য দিলে নেট লাভ। "পাওনা" = ডেলিভারড কিন্তু ক্যাশ হাতে আসেনি।
- **অফার:** 🎁 আগে-কিনেছেন/রেগুলার/সবার জন্য। কাস্টমার পরের বার মেসেজ করলে একবার নিজে যায়; "এখনই পাঠান" শুধু ২৩ ঘণ্টার ভেতরের কাস্টমারদের।
- **ছবি পাঠালে:** AI ছবি বর্ণনা করে, ক্যাটালগের ছবির সাথে মেলায় (ক্যাটালগ বড় হলে আগে কাছাকাছিগুলো বাছে), মিললে দাম-সহ কার্ড দেখায়। মিল-ফল ড্যাশবোর্ডে ছবির নিচে দেখা যায়।
- **কমেন্ট → ইনবক্স:** কমেন্টে দাম/অর্ডার/আগ্রহ চিনে (প্রশংসা, ইমোজি, স্প্যাম এড়ায়), পোস্টের লেখা দেখে প্রোডাক্ট চিনে কমেন্টে দামসহ উত্তর দেয় ও ইনবক্সে ক্যারোসেল পাঠায়। না পারলে লেখায় ফিরে যায়। রিপোর্টে কমেন্ট লগ।

## সৎ সীমাবদ্ধতা

- **২৪ ঘণ্টার নিয়ম:** কাস্টমারের শেষ মেসেজের ২৪ ঘণ্টা পরে Meta স্বয়ংক্রিয় মেসেজ (রিটার্নের কারণ জিজ্ঞেস, দেরিতে ডেলিভারির আপডেট, অফার) পাঠাতে দেয় না; ব্যর্থ হলে ড্যাশবোর্ডে লাল ⚠ দেখায়। টিমের নিজের লেখা মেসেজ Human Agent ফিচার থাকলে ৭ দিন পর্যন্ত যায়। WhatsApp-এ ২৪ ঘণ্টা পরে অনুমোদিত টেমপ্লেট লাগে (এখনো নেই)।
- **যা আমি আসল Meta/Gemini/Steadfast-এ চালিয়ে দেখতে পারিনি:** কার্ড-বাটনের আসল চেহারা, কমেন্টের প্রাইভেট রিপ্লাইয়ে ক্যারোসেল Meta নেয় কিনা, Steadfast ট্র্যাকিং লিংকের সঠিক ধরন, আসল Gemini-র উত্তরের মান। এসব নকল সার্ভার দিয়ে পরীক্ষা করেছি।
- **ট্র্যাকিং লিংক:** Steadfast-এর সরাসরি লিংক (`/t/কোড`) আর কাজ করছিল না, তাই কোড + সাধারণ ট্র্যাকিং পেজ পাঠানো হয়। সঠিক লিংকের ধরন পেলে `.env`-এ `TRACK_URL_TEMPLATE` দিন।
- **ডেটাবেস:** JSON ফাইল। শত শত অর্ডার/দিনে ঠিক আছে, বড় হলে Postgres লাগবে।
- **এখনো নেই:** অন্য ব্যবসার sign up (multi-tenant), Pathao/RedX, ডেলিভারির দিন সকালে রিমাইন্ডার, উত্তর না পাওয়া কমেন্টে দ্বিতীয়বার রিপ্লাই, WhatsApp টেমপ্লেট।
